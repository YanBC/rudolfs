Connect a repository

Three steps. Your usual Git workflow from there.

Use letters, numbers, dots, underscores, or hyphens. Commands update as you type.

Enter both names using the characters above. A name cannot be just . or ..

01

Point Git LFS to this server

Run git lfs install first. Then create .lfsconfig in the root of your repository:

.lfsconfig
[lfs]
url = "{{ api }}/my-org/my-repo"

This URL is your storage namespace. Use a unique pair of names for each project to keep its objects separate.

02

Choose what belongs in LFS

Track a file pattern. For example, use *.psd for Photoshop files. Repeat for each file type you need.

Terminal · repository root
git lfs track "*.psd"
git add .lfsconfig .gitattributes
git commit -m "Configure Git LFS"
03

Add assets. Push as usual.

With your file patterns configured, Git LFS handles new assets automatically. Replace design.psd with your file.

Terminal · repository root
git add design.psd
git commit -m "Add design asset"
git push

Already have large files in Git history? Tracking a pattern only affects new additions. Read the migration guide before rewriting history.

Before you begin

A quick checklist

  • 01
    Install the Git LFS client on every machine that uses large assets.
  • 02
    Work inside an existing Git repository with a remote configured.
  • 03
    Make sure your machine can reach this server’s address.

Working with a team?

Commit both .lfsconfig and .gitattributes so everyone shares the same setup.

Rudolfs has no built-in client authentication. Use a trusted network or ask your administrator about access controls.

Check your connection

Run git lfs env and check that the endpoint matches your repository URL. Use git lfs ls-files to see tracked assets.
